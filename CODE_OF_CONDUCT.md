# Subagent MCP Code of Conduct

Subagent MCP contributors must make participation respectful, safe, and
welcoming regardless of background, identity, experience, or viewpoint.

Expected behavior includes constructive technical feedback, respect for
boundaries and privacy, acknowledgment of mistakes, and focus on the project's
public benefit. Harassment, threats, discrimination, sexualized conduct,
doxxing, publishing private credentials/transcripts, or sustained personal
attacks are unacceptable.

Maintainers may edit, hide, reject, or remove contributions and participation
that violate this policy. Report conduct concerns privately through the
repository's moderation or security-advisory channel. Maintainers should limit
disclosure to what is necessary, investigate fairly, avoid retaliation, and
state any enforcement action proportionately.

This policy applies in Subagent MCP repositories, issue trackers, reviews,
release spaces, and public representation of the project.
